# Não faça isso

## Contexto
- Não transforme AGENTS.md em enciclopédia.
- Não carregue toda a KB em toda tarefa.
- Não leia o repositório inteiro antes de começar.
- Não cole logs enormes.
- Não repita documentação oficial integralmente.
- Não mantenha instruções antigas só porque já existem.

## Código
- Não reescreva arquivo inteiro para mudança pequena.
- Não crie manager/autoload para todo sistema.
- Não introduza abstração antes da necessidade.
- Não otimize sem profiler.
- Não troque versão do Godot sem decisão explícita.

## Design
- Não cole features de referências.
- Não expanda conteúdo antes de provar core loop.
- Não confunda mais stats com progressão interessante.

## Visual
- Não use noise/glow/particles como substituto de direção de arte.
- Não aprove arte sem render/captura.
- Não deixe VFX esconder telegraph.

## QA
- Não entregue 100 problemas sem prioridade.
- Não chame preferência estética de blocker.
- Não aceite bug sem repro quando repro é possível.
