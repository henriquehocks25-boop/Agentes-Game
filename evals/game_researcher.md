# Eval — Game Researcher

## Tarefas
1. Analisar jogo por fontes primárias + gameplay + feedback.
2. Distinguir fato, hipótese e opinião.
3. Encontrar padrão recorrente sem inventar percentual.
4. Produzir keep/improve/remove/add.
5. Criar diferenciação sem copiar expressão.

## Benchmark visual
Duas referências visuais + uma captura atual. Identificar pelo menos cinco diferenças observáveis que orientam design de assets (e não apenas shaders), sem copiar expressão específica.

## Medir
- qualidade das fontes;
- triangulação;
- causalidade prudente;
- originalidade;
- concisão;
- **decision yield**: quanto da pesquisa muda uma decisão;
- parou por saturação ou continuou por volume;
- tamanho do handoff.
