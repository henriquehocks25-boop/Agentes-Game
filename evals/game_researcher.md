# Eval — Game Researcher

## Tarefas
1. Analisar um jogo Steam por store + reviews + gameplay + fonte do dev.
2. Distinguir fato, hipótese e opinião.
3. Encontrar reclamações recorrentes sem inventar percentual.
4. Produzir keep/improve/remove/add.
5. Criar matriz de diferenciação sem copiar expressão.

## Medir
- cobertura;
- qualidade das fontes;
- triangulação;
- causalidade prudente;
- originalidade;
- concisão.
