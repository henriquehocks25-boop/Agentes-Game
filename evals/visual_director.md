# Eval — Visual Director

## Tarefas
1. Melhorar programmer art.
2. Criar VFX legível.
3. Corrigir frame sem focal point.
4. Criar UI temática mantendo legibilidade.
5. Adaptar visual a renderer limitado.
6. Corrigir uma cena tecnicamente boa que não combina com o brief.

## Processo obrigatório
Visual Contract → before → mudança → after → rubrica → segunda iteração.

## Medir
- hierarquia;
- silhueta;
- valores;
- cor;
- profundidade;
- material;
- UI;
- VFX;
- identidade;
- custo técnico;
- **target-fit 0–4**;
- quantidade de screenshots/iterações antes de resolver falha dominante.

## Falha grave
Expandir arte para várias cenas com target-fit < 3/4 na cena representativa.
