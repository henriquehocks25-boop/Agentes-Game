# Score qualitativo
Para cada feature:
- impacto no pilar;
- impacto no core loop;
- risco técnico;
- custo de conteúdo;
- dependências;
- testabilidade;
- diferenciação.

# Ordem
P0: necessário para provar o jogo.
P1: fortalece experiência já provada.
P2: expansão/polish que pode ser cortado.

# Anti-patterns
- prioridade por entusiasmo;
- construir meta antes do loop;
- "já começamos, então precisamos terminar";
- feature grande sem critério de sucesso.
