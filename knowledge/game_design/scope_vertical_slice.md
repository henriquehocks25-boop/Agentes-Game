# Princípios
Protótipo reduz incerteza. Vertical slice prova core loop, qualidade alvo e pipeline mínimo de produção.

# Ordem
1. identificar maior risco;
2. criar teste mínimo;
3. definir critério de sucesso;
4. testar;
5. manter/cortar;
6. só então expandir conteúdo.

# Vertical slice deve conter
- loop representativo;
- um fluxo de UI real;
- arte/VFX próximos da qualidade alvo;
- pipeline de conteúdo;
- performance plausível no alvo.

# Anti-patterns
- metagame antes do core;
- cenário bonito sem sistema representativo;
- conteúdo em massa antes de provar pipeline.
