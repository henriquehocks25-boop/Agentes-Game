# Princípios
- pilares descrevem experiências/decisões que o jogo protege;
- core loop descreve ações e feedback repetidos;
- meta loop conecta várias repetições por progressão/objetivo;
- MDA ajuda a ligar mecânicas a dinâmicas e experiência.

# Teste de feature
- qual pilar reforça?
- qual escolha cria?
- qual loop alimenta?
- qual consequência fica legível?
- qual custo adiciona?
- remover piora o jogo?

# Anti-patterns
- pilar como slogan temático;
- meta progressão compensando core loop fraco;
- feature sem loop ou decisão associada.
