# Princípios
Retenção saudável vem de valor recorrente: domínio, descoberta, progressão, expressão e comunidade — não de confusão ou coerção.

# Evitar
- urgência falsa;
- padrões que escondem custo;
- punição desproporcional por ausência;
- interfaces que dificultam cancelar/recusar;
- manipulação de menores ou vulneráveis.

# Para o agente
Ao propor retention, explicar qual valor de jogo faz o jogador querer voltar. Se a resposta depende de medo de perder algo, reavaliar.
