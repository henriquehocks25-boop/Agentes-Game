# Princípios
Conteúdo deve ampliar decisões ou contexto; quantidade sozinha não corrige repetição.

# Matriz
Para cada tipo de conteúdo registre:
- função;
- custo de produção;
- combinações sistêmicas;
- frequência;
- reutilização;
- dependências.

# Padrões
Crie pequeno conjunto de peças que combinam bem antes de centenas de peças isoladas.

# Anti-patterns
- enemy reskin como variedade principal;
- conteúdo manual em massa antes de pipeline;
- recompensa nova que não muda comportamento.
