# Princípios
Feedback fecha o loop ação → consequência. Priorize latência percebida, legibilidade e coerência antes de quantidade de efeitos.

# Canais
- movimento/câmera;
- animação;
- hit stop/timing;
- VFX;
- áudio;
- UI;
- reação do alvo;
- números/texto quando necessários.

# Padrões
Evento importante deve ter feedback proporcional e redundância útil entre canais.

# Anti-patterns
- screen shake constante;
- efeitos atrasados em relação ao hit;
- feedback bonito que mascara ameaça;
- "juice" usado para esconder controles imprecisos.
