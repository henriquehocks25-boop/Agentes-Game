# Princípios
Documento vivo existe para reduzir ambiguidade de produção, não para descrever antecipadamente cada detalhe.

# Estrutura
- visão/pilares;
- player verbs;
- loops;
- sistemas;
- conteúdo;
- progression/economy;
- UX;
- art direction;
- restrições técnicas;
- decisões abertas;
- changelog de decisões importantes.

# Anti-patterns
- GDD de dezenas de páginas ignorado;
- duplicar specs em arquivos diferentes;
- documentar implementação que o código já explica;
- deixar decisão antiga ativa após mudança.
