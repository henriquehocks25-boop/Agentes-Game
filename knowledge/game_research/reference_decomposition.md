# Escalas de tempo
- 1–5 s: input, reação, microfeedback;
- 10–60 s: decisão tática/encontro;
- minutos: objetivo da sessão/run;
- horas: progressão/meta;
- longo prazo: mastery/coleção/conteúdo.

# Decomponha
verbos → regras → recursos → inimigos/obstáculos → rewards → progression → feedback → failure/recovery.
