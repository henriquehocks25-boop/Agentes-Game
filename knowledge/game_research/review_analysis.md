# Princípios
Reviews são feedback auto-selecionado. Use para detectar temas e hipóteses, não para estimar toda a população sem método adequado.

# Amostra
Misture recomendadas/não recomendadas, recentes/antigas e diferentes faixas de tempo de jogo.

# Tags
core loop, balance, repetição, UX, performance, conteúdo, onboarding, controles, visual, áudio.

# Regras
- registrar contexto de Early Access/update;
- evitar percentual sem amostra/metodologia;
- não confundir frequência textual com importância causal;
- triangular com gameplay e fontes do desenvolvedor.
