# Segunda matriz
Para o novo jogo:
- KEEP: princípio comprovado que combina com nossos pilares;
- IMPROVE: problema com oportunidade clara;
- REMOVE: sistema sem função no conceito;
- ADD: diferenciação que reforça pilares.

# Regra
Não combine "as melhores features" de vários jogos sem validar se formam um sistema coerente.
