# Quando usar
Pesquisa independente, tarefa paralela bem delimitada ou domínio especializado.

# Quando evitar
Mudança simples ou subtarefa que exige quase todo o mesmo contexto.

# Contrato
Objetivo, limites, inputs, caminhos relevantes, formato de saída e critério de conclusão.

# Regra
Delegação pode reduzir contexto local, mas pode aumentar trabalho total. Use somente quando o isolamento traz benefício claro.

# Handoff
Retorne fatos, arquivos, decisão, evidência e riscos.
