# Competency Matrix — Basic → Intermediate → Advanced → Professional

Uma competência profissional exige **entrega em jogo, diagnóstico, medição e revisão**, não apenas conhecer o nome da ferramenta.

| Disciplina | Básico | Intermediário | Avançado | Evidência de prática profissional |
| --- | --- | --- | --- | --- |
| Game design | regras/objetivos | loops/progressão | economias/balanceamento sistêmico | hipóteses testadas, decisões, escopo e iteração |
| Level/world design | salas/rotas | pacing/checkpoints | ecologia de encontros/telegraph/biomas | mapas jogados, heatmap/observações e revisão |
| Godot/GDScript | scenes/nodes | signals/resources | composição, dependências, tools, dados | código escalável, perfis, migração e testes |
| Gameplay | movimento/interação | combate/inventário/quests | save consistente, estados, input edge cases | vertical slice integrado sem regressões |
| Game AI | FSM | percepção + navegação | utility/BT/squads/steering | debug visual, simulação e comportamento legível |
| Matemática | vetores/ângulos | transformações/curvas | quaternions, ruído, probabilidade | fórmulas aplicadas, tests e estabilidade numérica |
| Arte 2D | forma/cor | silhueta/material | concept/sprites/anim | assets originais, revisão em 1x e consistência |
| Arte 3D | mesh/UV | PBR/rig/luz | topologia, baking, LOD, modular kits | pipeline editável, budgets e render in-game |
| Technical art | parâmetros | ferramentas/shaders | procedural systems e render pipelines | sistema dirigível por artista, profiling e QA |
| Shaders | uniform/fragment | normals/masks/SDF | screen/depth/lighting/perf | fidelidade visual, plataformas e métricas |
| Animação | keyframes | anticipation/timing | blend/IK/procedural | clareza de pose, grounding e integração |
| VFX | partículas | layers/telegraphs | GPU budgets, distorção e composição | feedback claro sem ocluir gameplay |
| Iluminação/render | luz/sombra | PBR/tone mapping | HDR/AO/GPU tradeoffs | target-fit + legibilidade + orçamento |
| Áudio | SFX/music | buses/spatial | mix/dinâmica/memória | audition em jogo e controle de níveis |
| UI/UX | HUD | menus/focus | fluxos, error prevention, UX testing | resolução/input/acessibilidade validados |
| PC input | keyboard | mouse/gamepad/remap | hotplug/deadzone/multi-res | teste em dispositivos reais |
| Acessibilidade | texto/contraste | captions/remap | assistências configuráveis | matriz de necessidades e playtests |
| Performance | FPS | profiler CPU/GPU | budgets, p95/p99, memória/VRAM | perf repetível em hardware alvo |
| Arquitetura | pastas | modules/resources | interfaces, ADR, migração | testes, desacoplamento e manutenção |
| QA | smoke | regressão/repro | risk-based, compatibilidade | bugs priorizados + evidências |
| Polish | hit flash | câmera/áudio/VFX integrados | consistência perceptual/latência | before/after e feedback testado |
| Build/release | export | presets/config/save | Steam/CI/rollback/compat | binário Windows testado fora do editor |

Para cada linha, consulte o playbook de domínio e execute o benchmark correspondente. Esta matriz é mapa de escopo, não alegação de que a equipe já domina os níveis avançados.
