# Princípios
Conte história pelo estado do mundo, relações espaciais e consequências visíveis antes de depender de texto.

# Padrões
- props com causa contextual;
- wear/damage coerentes;
- contraste entre áreas para mostrar mudança;
- sinais visuais repetidos para facções/eventos.

# Anti-patterns
- clutter sem narrativa;
- detalhe que contradiz gameplay;
- texto expositivo para explicar algo que o ambiente deveria mostrar.
