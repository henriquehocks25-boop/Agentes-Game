# Princípios
HUD serve decisões. Elementos persistentes precisam justificar espaço e contraste.

# Padrões
- informação crítica próxima da atenção quando possível;
- tipografia legível;
- estados claros;
- não depender só de cor;
- esconder/reduzir elementos fora de contexto;
- suporte consistente ao input.

# Anti-patterns
- card para toda informação;
- borda/glow como hierarquia única;
- fonte temática ilegível;
- HUD cobrindo centro de ação.
