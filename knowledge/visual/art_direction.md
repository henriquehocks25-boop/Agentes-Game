# Art Bible mínima
- intenção emocional;
- referências por princípio;
- value structure;
- paleta;
- shape language;
- materiais;
- iluminação;
- câmera;
- UI/typography;
- VFX rules;
- exemplos de "não pertence".

# Princípios
Direção de arte é sistema de restrições coerentes. Identidade não vem de adicionar detalhes, mas de escolhas consistentes.

# Anti-patterns
- moodboard sem regras;
- copiar uma única referência;
- estilo diferente por asset;
- pós-processamento escondendo base fraca.
