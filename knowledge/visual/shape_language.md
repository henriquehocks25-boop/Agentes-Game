# Princípios
Forma comunica função, personalidade e perigo antes de detalhe. Silhueta precisa sobreviver a distância e movimento.

# Padrões
- famílias de formas por facção/tipo;
- contraste de proporção entre papéis;
- silhueta distinta para ameaças importantes;
- detalhe interno só depois da leitura macro.

# Anti-patterns
- mesma base para todos os inimigos com troca de cor;
- detalhe destruindo contorno;
- shape language contraditória sem intenção.
