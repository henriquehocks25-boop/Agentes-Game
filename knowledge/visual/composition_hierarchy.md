# Checklist do frame
- o foco de gameplay é encontrado primeiro?
- maior contraste está onde há decisão?
- player/inimigo/objetivo se separam do fundo?
- foreground/midground/background são legíveis?
- movimento conduz atenção?
- UI compete com ação?

# Princípio
Contraste é orçamento. Reserve contraste alto para informação importante.

# Anti-patterns
- tudo saturado;
- tudo brilhando;
- detalhe uniforme;
- partículas sobre telegraphs;
- fundo com contraste maior que alvo.
