# Verifique
- clipping/z-fighting;
- missing material/texture;
- lighting inconsistente;
- particle pop;
- UI overlap;
- text overflow;
- shader diferente por renderer;
- camera clipping;
- animation pop;
- feedback ilegível.

# Evidência
Screenshot/video + cena + renderer + resolução.

# Regra
Consistência visual não é só gosto: reporte quebra objetiva separada de sugestão estética.
