# Baseline
- remapeamento quando aplicável;
- texto legível;
- alto contraste útil;
- nada essencial só por cor;
- nada essencial só por som;
- subtitles para fala importante;
- volumes separados;
- settings persistem;
- UI acessível pelo mesmo método de input do gameplay quando aplicável.

# Processo
Considerar cedo no design e incluir pessoas com deficiência em playtests quando possível.

# Nota
Nem toda guideline se aplica a todo jogo; priorize por mecânica e público.
